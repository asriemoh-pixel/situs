🔗 Alamat Link HTTPS

Agar link bisa dibuka peserta dari HP/perangkat lain, file harus di-host pada alamat HTTPS. File lokal (file://) tidak dapat berubah menjadi link HTTPS yang benar-benar dapat diakses.

☁️ Server Pengumpulan Jawaban

Gunakan satu URL server yang sama pada HTML guru dan semua HTML siswa. Dengan ini kode ujian yang sama dapat dipakai di perangkat berbeda dan jawaban terkumpul di satu tempat.
